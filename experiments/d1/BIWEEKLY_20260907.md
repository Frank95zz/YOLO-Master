报告区间：2026-08-24 至 2026-09-07（北京时间）。

**本期成果摘要**

- 完成冻结 DINOv3 多层特征、离线缓存、多尺度适配、LatentMixture 与检测头的训练评测闭环，并完成完整 COCO 2017 的 100 轮训练。
- best/last 权重分别完成全部 5,000 张验证图片的独立评测：best 的 COCO AP/AP50 为 **11.972/23.726**，last 为 **11.489/22.956**。[最终评测证据](https://github.com/Frank95zz/YOLO-Master/blob/c44025eb36e63e4e858306b6e138a9d3c0f3aebd/experiments/d1/manifests/final-evaluation-20260907.json)
- 完成逐图 NPY 缓存与 NVMe 存储优化；同配方首轮耗时由 **825.101 秒降至 146.541 秒**。最终 100 轮训练及逐轮验证累计 **3.947 小时、23.68 GPU-hours**。

**阶段判断：** 工程链路与存储瓶颈优化已得到验证，但当前冻结方案精度不足，尚未证明满足双数据集对照和训练成本降低至少 50% 的目标。下一阶段优先验证空间特征融合与辅助损失配置。

## 1. 问题与假设

**要验证的问题：冻结 DINOv3 基础模型，仅训练多尺度适配器、LatentMixture 与检测头，能否在保留足够检测精度的同时，降低相对于近似同参数量从零训练检测器的训练成本？**

| 假设 | 本期验证方法 | 当前判断 |
| --- | --- | --- |
| 冻结特征能够支撑检测训练 | 多层特征接口、缓存一致性、小样本过拟合、完整 COCO 训练 | 100 轮训练及 best/last 完整独立评测完成；精度仍需提升 |
| 冻结方案具有精度与成本收益 | 近似同参数量 Scratch 对照，记录精度、显存和 GPU-hours | 只有单 seed 初步对照，尚不能证明满足课题成本目标 |
| 大特征缓存的存储读取限制训练速度 | 相同 NPY 内容、相同修复版模型及配方，仅切换 SATA/块设备与 NVMe | 首轮耗时和数据等待显著改善，支持存储瓶颈判断 |

本实验将同参口径固定为**可训练参数数量差异绝对值不超过 1%**；同时单列冻结 Teacher 的参数、抽取成本和推理依赖。该容差是实验匹配口径，不是课题原文给出的阈值。双数据集对照、精度保留比例及至少一个数据集 GPU-hours 降低至少 50% 的目标仍待验证。

模型链路：

`冻结 DINOv3 ViT-S/16 → block4/8/12 离线特征 → 9 条 Adapter 分支 → P3/P4/P5 各自的 LatentMixture → YOLO26 Detect`

三个输入层同为 stride 16。Adapter 后每个尺度各有三个候选，再由该尺度的 LatentMixture 输出 P3 `[B,64,80,80]`、P4 `[B,128,40,40]`、P5 `[B,256,20,20]`。下游共有 **3,542,567 个可训练参数**。当前 `router_only` 的主空间内容来自 block4，其他层提供路由条件；三层空间内容尚未直接加权融合，这是下一阶段对照实验的重点。

## 4. 结论、不确定性与已知局限

**已经得到的证据：** 冻结多层特征到检测训练的组件链路可运行；缓存具备校验和恢复能力；小样本能够拟合；完整 COCO 训练记录可追溯，best/last 独立评测已补齐；NVMe 明显降低了该运行配置下的数据等待。

**仍待验证：** 冻结方案的精度保留能力、端到端 GPU-hours 降低至少 50% 的目标、第二数据集对照，以及多 seed 统计和置信区间。旧 30 轮与新 100 轮结果不能混算精度保留率；当前初步对照尚不支持冻结方案具有收益。

| 风险／局限 | 已观察事实与证据 | 处理和停止条件 |
| --- | --- | --- |
| 冻结方案精度不足 | 验证及 train5000 对照均明显落后；修复版后半程没有持续提升 | 先做短预算空间融合/aux 消融；未出现稳定改善不重复堆叠大规模训练 |
| 特征批上下文依赖 | 16 图中两张尾批样本单图重算不一致 | 抽取/重算记录 batch 和分区；重现原上下文仍不一致则停止使用对应缓存 |
| 训练性能受存储影响 | SATA 与 NVMe 首轮耗时差异明显 | 新机器先做短 I/O 基准；吞吐或显存/内存异常时暂停扩展，不能沿用本机 ETA |
| 跨机器复现材料 | 代码和脱敏摘要已提交推送；完整依赖锁、运行归档及大文件未全部公开 | 按发布 commit 和合同准备环境、数据及缓存，重新验证；不能将代码可克隆等同于完整离线复现包 |
| 数据与存储责任 | NVMe 为临时空间；COCO 图片许可及 DINOv3 许可需单独遵循 | 保留许可来源、数据列表与权重摘要；可再生大缓存与不可替代实验记录分开管理 |

### 优先实验：空间特征融合与辅助损失对照

**目标：** 验证让 block8、block12 的空间特征直接参与检测，是否改善当前冻结方案的拟合能力与验证精度。
当前 `router_only` 的主空间内容来自 block4；`weighted_sum` 在每个尺度内部融合三层 Adapter 输出，再送入专家网络，仍保留 Router 对专家的动态加权。

| 组别 | `value_fusion_mode` | 三层空间融合权重 | `latent_aux_gain` | 对照目的 |
| --- | --- | --- | ---: | --- |
| A | `router_only` | 不直接融合三层空间内容 | 0.1 | 同预算基线 |
| B | `weighted_sum` | `[1,1,1]`，归一化为各 1/3 | 0.1 | 与 A 比较空间融合的作用 |
| C | `weighted_sum` | `[1,1,1]`，归一化为各 1/3 | 0 | 与 B 比较辅助损失的作用 |

三层融合权重是固定配置，不是可学习参数；C 仅关闭 latent aux 对总损失的贡献，不关闭 Router 或专家网络。
三组均保留 **3,542,567** 个可训练参数，复用现有 COCO NPY 缓存，不重新抽取 Teacher 特征。

1. **先做小样本验收。** 核对输出形状、有限 loss、严格重载，以及九条 Adapter 分支的检测梯度；已有初始化探针显示等权融合能够为九条分支提供非零梯度，但这不是正式精度结论。
2. **再做同预算训练。** A/B/C 都从相同初始化规则开始，可对应的参数初值保持一致，不加载旧 `router_only` 的已训练权重。固定同一 COCO 划分及样本顺序、seed 0、640 输入、全局 batch 384、AMP、优化器和无增强设置。三组使用相同短训练预算及学习率调度；具体轮数与判据在启动前锁定，不把已有 100 轮 A 与新的短预算 B/C 直接比较。
3. **按 A→B、B→C 分别分析。** 统一记录检测 loss、独立 COCO AP/AP50、AP small/medium/large、Router 与 Adapter 梯度、epoch 耗时、峰值显存及 GPU-hours。A/B 只归因于融合方式，B/C 只归因于辅助损失开关。
4. **有效后再扩展。** 只有短预算结果支持精度或拟合改善，才推进完整预算和多 seed 验证；若无改善，保留负结果，再考虑可学习融合权重或拼接卷积。这两种扩展不是当前已有配置选项，也不在本轮默认实施范围内。

预期交付：三组配置与源码身份、训练曲线、统一评测表及耗时/显存对照。上述实验尚未开展；单 seed 的改善不作为统计显著性结论，融合方式对速度的影响需实测。
