## 3. 选择依据

只检查参数与结构合法性，不进行 AP 试训选型。标准 YOLO26 的骨干、Neck、模块连接和检测头保持不变，不添加闲置参数。两个数据集使用同一骨干/Neck，仅改类别数。

| 候选 | depth / width / cap | VisDrone 参数 | COCO 参数 | 判断 |
| --- | --- | ---: | ---: | --- |
| 标准 S | 0.5 / 0.5 / 1024 | 9,955,604 | 10,009,784 | 小约 56%，不匹配 |
| 标准 M | 0.5 / 1.0 / 512 | 21,788,308 | 21,896,248 | 小约 5%，不匹配 |
| M 邻近宽度 | 0.5 / 1.015625 / 512 | 22,601,960 | 22,713,260 | 两数据集均超过 1% 偏差 |
| M 邻近宽度 | 0.5 / 1.03125 / 512 | 23,178,032 | 23,289,332 | 两数据集均超过 1% 偏差 |
| 标准 L | 1.0 / 1.0 / 512 | 26,191,764 | 26,299,704 | 大约 14%，不匹配 |
| M 同时改 cap/宽度 | 0.5 / 1.015625 / 520 | 23,026,080 | 23,137,380 | 可行，但双数据集最大偏差 0.5913% |
| **选定 L 宽度匹配版** | **1.0 / 0.9375 / 512** | **23,032,340** | **23,133,560** | **最大偏差 0.5746%，且保留标准 cap** |

还检查了 M width=1.046875/1.0625 和 M cap520/width1.0，均不满足 1%。L width=0.921875 不满足现有 C2PSA 注意力 reshape 的通道约束，直接排除，不修改模块实现来容纳它。

这是已检查候选中的选择，不宣称穷举所有架构后的全局最小参数误差。两个可行候选中采用双数据集最大相对偏差更小、保留标准 cap 的方案。

## 4. 网络结构

```text
RGB 640 x 640
  -> Conv + C3k2 多阶段骨干
  -> SPPF + C2PSA
  -> 上采样/Concat/C3k2 的自顶向下路径
  -> stride-2 Conv/Concat/C3k2 的自底向上路径
  -> P3 [B,240,80,80]
     P4 [B,480,40,40]
     P5 [B,480,20,20]
  -> YOLO26 end-to-end Detect (reg_max=1)
```

scale 保持 `l`，以保留仓库 parser 的 L 分支行为。通道按 parser 规则对齐，不把 YAML 标称值直接当成实际通道。

Scratch 不包含 DINOv3、缓存输入或 LatentMixture。它是同总参数的端到端 RGB 系统对照，不是隔离预训练、冻结、融合各因素的同架构因果消融；后者不能由本对照替代。

## 6. 正式对照约束

- 新鲜运行从 YAML 随机初始化，不从旧 Scratch 或官方权重续训。
- 复用 E4 的完整数据、三 seed 和统一评测原则；预算仍需正式锁定。
- Scratch RGB 和 Frozen NPY 均使用 NVMe，计时包含实际数据等待。
- 单列 Teacher 抽取成本、下游训练/验证 GPU-hours、独立评测和总墙钟。
- 总参数相近不代表计算量、显存或训练时间相同，也不预先保证 50% 成本下降。
- 预训练 Teacher 带有外部预训练信息，其原始预训练成本未计入本项目增量成本；报告必须明确这一边界。
